### 💡 Concepts & Theory
- **New Concepts**:
  - **EC2**: Dịch vụ tính toán đám mây, hỗ trợ mở rộng linh hoạt, tích hợp với Security Groups và VPC.
  - **Instance Types**: General Purpose (t3, m5), Compute Optimized (c5), Memory Optimized (r5), Storage Optimized (i3), Accelerated Computing (p3).
  - **AMI**: Mẫu hình ảnh chứa hệ điều hành (Amazon Linux, Ubuntu, Windows), phần mềm, và cấu hình để khởi động instance (Public, Private, Marketplace AMIs).
  - **Backup**: Full (toàn bộ dữ liệu), Incremental (chỉ thay đổi), Differential (thay đổi từ Full Backup cuối).
  - **Key Pair**: Cặp khóa (Public/Private) để xác thực SSH, cần bảo vệ Private Key.
  - **EBS**: Lưu trữ khối bền vững, hỗ trợ snapshot, các loại như gp2/gp3 (General Purpose), io1/io2 (IOPS cao), st1 (Throughput Optimized), sc1 (Cold HDD).
  - **Instance Store**: Lưu trữ tạm thời, hiệu suất cao, mất dữ liệu khi instance dừng.
- **Best Practices**: Chọn Instance Type phù hợp; sử dụng AMI để triển khai nhanh; sao lưu EBS bằng snapshot; bảo vệ Private Key.
- **Industry Knowledge**: EC2 là nền tảng cốt lõi để triển khai ứng dụng web, phân tích dữ liệu, và phát triển phần mềm.
