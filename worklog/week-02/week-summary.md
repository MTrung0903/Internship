## 📚 Kiến thức học được
- **Kỹ thuật**:
  - **Dịch vụ AWS**: Amazon VPC, EC2, Route 53 Resolver, CloudFormation, Security Groups, Network ACLs, VPN, Direct Connect, ELB.
  - **Công cụ**: AWS Management Console, CloudFormation Designer, SSH client, RDP client, draw.io.
  - **Kiến trúc**: Thiết lập VPC với Public/Private Subnets, cấu hình bảo mật với Security Groups/Network ACLs, triển khai EC2, và tự động hóa với CloudFormation.
- **Lý thuyết**:
  - VPC: Public/Private Subnets, Route Table, Internet Gateway, NAT Gateway, Security Groups (stateful), Network ACLs (stateless), VPC Flow Logs, VPC Peering, Transit Gateway.
  - Kết nối mạng: VPN (Site-to-Site, Client-to-Site), Direct Connect, Elastic Load Balancing (ALB, NLB).
  - Route 53 Resolver: Hybrid DNS, Inbound/Outbound Endpoints, Resolver Rules.
  - EC2: Instance Types (General Purpose, Compute Optimized, v.v.), AMI, EBS, Instance Store, Key Pair.
  - CloudFormation: Tự động hóa triển khai tài nguyên bằng template YAML.
- **Kỹ năng mềm**:
  - Ghi chú chi tiết, quản lý thời gian, tự học qua video và tài liệu AWS.
  - Giải quyết vấn đề: Xử lý lỗi cấu hình CloudFormation, SSH, DNS, và Security Groups.
  - Trực quan hóa kiến trúc qua sơ đồ draw.io và VPC Resource Map.
