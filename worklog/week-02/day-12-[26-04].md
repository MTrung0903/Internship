- **Kết quả**: Hiểu khái niệm Hybrid DNS và vai trò của Route 53 Resolver trong xử lý truy vấn DNS.
- **Tools/Tech**: AWS Management Console, AWS Route 53.

### 2. Thực hành Lab 10-02.1: Tạo Key Pair 
- **Mô tả**: Tạo cặp khóa SSH (aws-keypair) qua AWS Management Console và lưu khóa Private để kết nối EC2.
- **Kết quả**: Tạo thành công Key Pair và lưu trữ khóa Private an toàn.
- **Tools/Tech**: AWS Management Console.

### 3. Thực hành Lab 10-02.2: Khởi tạo CloudFormation Template 
- **Mô tả**: Sử dụng template YAML để tự động triển khai VPC, Subnets, Route Tables, và các tài nguyên cần thiết cho Hybrid DNS.
- **Kết quả**: Triển khai thành công các tài nguyên qua CloudFormation Stack.
- **Tools/Tech**: AWS CloudFormation, AWS Management Console.

### 4. Thực hành Lab 10-02.3: Cấu hình Security Group 
- **Mô tả**: Cấu hình Security Group để cho phép lưu lượng DNS (TCP/UDP port 53) và SSH (TCP port 22) từ các nguồn IP cụ thể.
- **Kết quả**: Security Group được cấu hình đúng, cho phép kết nối cần thiết.
- **Tools/Tech**: AWS Management Console, AWS VPC.

### 5. Thực hành Lab 10-03: Kết nối đến RDGW 
- **Mô tả**: Kết nối đến Remote Desktop Gateway (RDGW) bằng Remote Desktop Protocol (RDP) qua địa chỉ IP công cộng.
- **Kết quả**: Kết nối RDP thành công, sẵn sàng cấu hình DNS và các dịch vụ liên quan.
- **Tools/Tech**: RDP client, AWS Management Console.

### 6. Thực hành Lab 10-05: Thiết lập DNS 
- **Mô tả**:
  - **Lab 10-05.1**: Tạo Route 53 Outbound Endpoint để chuyển tiếp truy vấn DNS từ VPC đến mạng on-premises.
  - **Lab 10-05.2**: Tạo Route 53 Resolver Rules để kiểm soát chuyển tiếp truy vấn DNS.
  - **Lab 10-05.3**: Tạo Route 53 Inbound Endpoint để mạng on-premises gửi truy vấn DNS đến AWS.
  - **Lab 10-05.4**: Kiểm tra truy vấn DNS từ cả hai hướng (AWS → on-premises, on-premises → AWS).
- **Kết quả**: Cấu hình thành công Hybrid DNS, kiểm tra truy vấn DNS hoạt động đúng ở cả hai chiều.
- **Tools/Tech**: AWS Route 53, AWS Management Console.

## 🚧 Khó khăn và giải pháp

### Vấn đề 1: Lỗi triển khai CloudFormation Template
- **Mô tả**: Stack CloudFormation thất bại do lỗi cú pháp trong template YAML.
- **Impact**: Gây gián đoạn khi triển khai VPC và Subnets.
- **Root Cause**: Thiếu tham số hoặc định dạng YAML không hợp lệ.
- **Solution**: Kiểm tra template bằng AWS CloudFormation Designer, sửa lỗi cú pháp dựa trên AWS Documentation.
- **Result**: Stack triển khai thành công.
- **Lesson**: Kiểm tra cú pháp YAML kỹ lưỡng trước khi triển khai.

### Vấn đề 2: Truy vấn DNS không hoạt động
- **Mô tả**: Truy vấn DNS từ AWS đến on-premises thất bại.
- **Impact**: Không thể kiểm tra Hybrid DNS.
- **Root Cause**: Route 53 Outbound Endpoint chưa được cấu hình đúng Subnet hoặc Security Group chưa mở port 53.
- **Solution**: Kiểm tra Outbound Endpoint và thêm quy tắc DNS (TCP/UDP 53) vào Security Group.
- **Result**: Truy vấn DNS hoạt động đúng.
- **Lesson**: Đảm bảo cấu hình Security Groups và Subnets cho Route 53 Resolver.
