### 1.Học lý thuyết Module 04-01: Dịch Vụ Lưu Trữ Trên AWS
- **Mô tả**: Đọc và ghi chú lý thuyết về các dịch vụ lưu trữ AWS:
  - **Amazon S3**: Object Storage, linh hoạt, phù hợp cho static website, backup, và dữ liệu không thường xuyên truy cập.
  - **Amazon EBS**: Block Storage, dùng làm volume cho EC2, phù hợp với database cần tốc độ cao.
  - **Amazon EFS**: File Storage, hỗ trợ hệ thống file chia sẻ cho nhiều instance.
  - **Amazon Glacier**: Lưu trữ dài hạn, chi phí thấp, phù hợp cho archiving.
  - **AWS Snow Family**: Thiết bị vật lý (Snowball, Snowcone, Snowmobile) để di chuyển dữ liệu từ on-premises lên AWS.
  - So sánh các mô hình lưu trữ: Object Storage (S3), File Storage (EFS), Block Storage (EBS).
- **Kết quả**: Hiểu rõ các dịch vụ lưu trữ AWS và trường hợp sử dụng của chúng.
- **Tools/Tech**: AWS Documentation, Notion (ghi chú).

### 2. Học lý thuyết Module 04-02: Amazon S3 - Access Point - Storage Class 
- **Mô tả**: 
    - **Access Point**: Điểm truy cập riêng biệt cho S3 bucket, giúp quản lý quyền truy cập theo nhóm người dùng hoặc ứng dụng, tăng bảo mật và đơn giản hóa quản lý.
    - **Storage Classes**:
      - **S3 Standard**: Độ trễ thấp, phù hợp cho dữ liệu thường xuyên truy cập.
      - **S3 Intelligent-Tiering**: Tự động di chuyển dữ liệu để tiết kiệm chi phí.
      - **S3 Standard-IA**: Chi phí thấp cho dữ liệu ít truy cập, phí truy xuất cao.
      - **S3 One Zone-IA**: Lưu trữ trong một Zone, chi phí thấp hơn Standard-IA.
      - **S3 Glacier**: Lưu trữ dài hạn, truy xuất chậm (phút đến giờ).
      - **S3 Glacier Deep Archive**: Lưu trữ dài hạn, truy xuất rất chậm, chi phí thấp nhất.
- **Kết quả**: Access Point được tạo thành công, hiểu cách quản lý quyền truy cập; file thử nghiệm được chuyển sang S3 Intelligent-Tiering.
- **Tools/Tech**: AWS Management Console, AWS S3, AWS IAM.
- **Links**: [Module 04-02 - Amazon Simple Storage Service ( S3 ) - Access Point - Storage Class](https://www.youtube.com/watch?v=_yunukwcAwc&list=PLahN4TLWtox2a3vElknwzU_urND8hLn1i&index=104)
