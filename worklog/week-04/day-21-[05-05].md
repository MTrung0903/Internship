### 💡 Concepts & Theory
- **New Concepts**:
  - **AWS Storage Gateway**: Dịch vụ kết nối on-premises với AWS, hỗ trợ File Shares (SMB) để đồng bộ dữ liệu với S3.
  - **S3 Bucket**: Lưu trữ file đồng bộ từ File Share.
  - **EC2 for Storage Gateway**: Sử dụng instance (m4.large) với EBS volume để chạy Storage Gateway.
  - **File Share SMB**: Gắn File Share lên máy Windows để truy cập như ổ đĩa cục bộ.
- **Best Practices**: Sử dụng tên bucket duy nhất; cấu hình Security Group tối thiểu; dọn dẹp tài nguyên sau lab.
- **Industry Knowledge**: Storage Gateway là giải pháp lai (hybrid) để kết nối hạ tầng on-premises với đám mây AWS.
