## 💼 Công việc đã thực hiện

### 1. Nghiên cứu Module 04-03: S3 Static Website & CORS - Control Access - Object Key & Performance - Glacier ⏱️ [2 giờ]
- **Mô tả**: Đọc và ghi chú lý thuyết về các khía cạnh của Amazon S3:
  - **S3 Static Website Hosting**: S3 có thể host website tĩnh bằng cách bật tính năng Static Website Hosting.
  - **CORS**: Cho phép ứng dụng từ domain khác truy cập bucket S3, cấu hình qua CORS policy.
  - **Control Access**: Sử dụng IAM Policies, Bucket Policy, và ACL để quản lý quyền truy cập ở mức bucket và object.
  - **Object Key & Performance**: Tối ưu hóa tên object (prefix) để giảm độ trễ; sử dụng CloudFront và Transfer Acceleration để tăng tốc độ.
  - **Amazon Glacier**: Lưu trữ dài hạn, chi phí thấp, tích hợp với S3 qua lifecycle rules; Vault Lock bảo vệ dữ liệu.
- **Kết quả**: Hiểu rõ các khái niệm và cách áp dụng S3 cho website tĩnh, kiểm soát truy cập, tối ưu hiệu suất, và lưu trữ Glacier.

- **Best Practices**: Sử dụng prefix để tổ chức object; cấu hình CORS và quyền truy cập tối thiểu; thiết lập lifecycle rules để tiết kiệm chi phí.
