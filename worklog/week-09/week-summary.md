## 📚 Kiến thức học được
- **Kỹ thuật**:
  - **Dịch vụ AWS**: AWS Backup, Storage Gateway, VM Import/Export, Amazon FSx, S3, EC2, SNS, Secrets Manager.
  - **Công cụ**: AWS Management Console, AWS CLI, VMware Workstation, Windows Command Prompt, RDP Client, File Explorer, Notion (ghi chú), draw.io.
  - **Kiến trúc**: Tích hợp hybrid với Storage Gateway và S3, di chuyển VM qua VM Import/Export, lưu trữ chia sẻ với FSx, quản lý backup với AWS Backup.
- **Lý thuyết**:
  - **Snow Family**: Snowcone, Snowball Edge, Snowmobile cho di chuyển dữ liệu lớn.
  - **Storage Gateway**: File Gateway (SMB), Volume Gateway, Tape Gateway cho tích hợp hybrid.
  - **AWS Backup**: Tự động hóa sao lưu và phục hồi cho EBS, S3, EC2, RDS, DynamoDB.
  - **VM Import/Export**: Chuyển đổi máy ảo giữa on-premises và EC2 qua S3.
  - **Amazon FSx for Windows File Server**: Hệ thống file chia sẻ Multi-AZ, tích hợp Windows Active Directory.
  - **S3 ACL**: Quản lý quyền truy cập ở mức bucket và object.
- **Kỹ năng mềm**:
  - Ghi chú chi tiết, quản lý thời gian, tự học qua AWS Documentation và video AWS Study Group.
  - Giải quyết vấn đề: Xử lý lỗi cấu hình File Share, SNS subscription, VM import/export, FSx connection, và S3 ACL.
  - Trực quan hóa kiến trúc qua sơ đồ draw.io.
