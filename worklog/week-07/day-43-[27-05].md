## 💼 Công việc đã thực hiện

### 1. Học lý thuyết Module 05-03: Amazon Cognito 
- **Mô tả**: Nghiên cứu và ghi chú về Amazon Cognito:
  - **Nội dung chính**:
    - **Khái niệm**: Dịch vụ quản lý danh tính và xác thực cho ứng dụng web/di động, hỗ trợ quy mô lớn (B2C/B2B).
    - **Chức năng chính**:
      - **User Pools**: Quản lý đăng ký/đăng nhập, hỗ trợ xác thực qua email, số điện thoại, mật khẩu, hoặc nhà cung cấp danh tính bên thứ ba (Google, Facebook, Apple) qua SAML 2.0/OIDC.
      - **Identity Pools**: Cấp thông tin xác thực AWS tạm thời (qua STS) để truy cập dịch vụ AWS (S3, DynamoDB).
      - **Tính năng bảo mật**: Hỗ trợ MFA, mã hóa dữ liệu, tích hợp AWS STS.
      - **Tùy chỉnh**: Sử dụng AWS Lambda để tùy chỉnh quy trình đăng ký/đăng nhập.
      - **Tích hợp**: Làm việc với AWS Amplify, API Gateway, hỗ trợ ứng dụng serverless.
    - **Lợi ích**: Dễ triển khai, tuân thủ SOC 1-3, ISO 27001, HIPAA-BAA, đồng bộ dữ liệu ngoại tuyến.
    - **Ứng dụng**: Phù hợp cho ứng dụng di động/web cần quản lý người dùng quy mô lớn.
  - **Hoạt động**:
    - Đọc tài liệu AWS về Cognito User Pools và Identity Pools.
    - Xem video AWS Study Group về tích hợp Cognito với Amplify.
    - Ghi chú sự khác biệt giữa User Pools và Identity Pools.
    - Liên hệ với lab S3 trước (Module 04-Lab57) để hiểu cách Cognito cấp quyền truy cập S3.
- **Kết quả**: Hiểu rõ Amazon Cognito, đặc biệt là User Pools, Identity Pools, và ứng dụng trong quản lý danh tính.
- **Tools/Tech**: AWS Documentation, AWS Study Group Videos, Notion (ghi chú).

### 2. Học lý thuyết Module 05-04: AWS Organizations 
- **Mô tả**: Nghiên cứu và ghi chú về AWS Organizations:
  - **Nội dung chính**:
    - **Khái niệm**: Dịch vụ quản lý tập trung nhiều tài khoản AWS, kiểm soát chi phí và bảo mật.
    - **Chức năng chính**:
      - **Quản lý tài khoản**: Tạo, nhóm tài khoản vào Organizational Units (OUs) theo phòng ban/dự án.
      - **Service Control Policies (SCPs)**: Giới hạn quyền truy cập dịch vụ AWS trong tài khoản/OU.
      - **Consolidated Billing**: Hợp nhất thanh toán, tối ưu hóa chi phí và ưu đãi giá.
      - **Tích hợp**: Làm việc với AWS Identity Center, AWS Billing.
    - **Lợi ích**: Đơn giản hóa quản lý, tăng bảo mật, tiết kiệm chi phí.
    - **Ứng dụng**: Phù hợp cho doanh nghiệp lớn với nhiều tài khoản AWS.
  - **Hoạt động**:
    - Đọc tài liệu AWS về AWS Organizations và SCPs.
    - Xem video AWS Study Group về quản lý tài khoản tập trung.
    - Ghi chú cách SCPs khác với IAM Policies (SCPs áp dụng ở cấp tổ chức, IAM ở cấp tài khoản).
    - Liên hệ với lý thuyết IAM (Module 05-02) để hiểu tích hợp với AWS Organizations.
- **Kết quả**: Hiểu rõ AWS Organizations, đặc biệt là cách quản lý tài khoản và áp dụng SCPs.
- **Tools/Tech**: AWS Documentation, AWS Study Group Videos, Notion (ghi chú).
- **Links**: [Module 05-04 - AWS Organization](https://www.youtube.com/watch?v=5oQY8Rogz9Y&list=PLahN4TLWtox2a3vElknwzU_urND8hLn1i&index=153)

### 3. Học lý thuyết Module 05-05: AWS Identity Center ⏱️ [2 giờ]
- **Mô tả**: Nghiên cứu và ghi chú về AWS Identity Center:
  - **Nội dung chính**:
    - **Khái niệm**: Dịch vụ đăng nhập một lần (SSO) để quản lý truy cập vào tài khoản AWS và ứng dụng doanh nghiệp.
    - **Chức năng chính**:
      - **SSO**: Đăng nhập một lần để truy cập tài khoản AWS và ứng dụng (Microsoft 365, Salesforce) qua SAML 2.0.
      - **Tích hợp danh tính**: Kết nối với Active Directory, Okta, hoặc IdP SAML.
      - **Quản lý quyền**: Gán quyền dựa trên vai trò, tích hợp với AWS Organizations.
      - **Tự động hóa**: Đồng bộ người dùng qua SCIM.
      - **Tích hợp Cognito**: Sử dụng Identity Center như IdP SAML cho Cognito user pools.
    - **Lợi ích**: Cải thiện trải nghiệm người dùng, tăng bảo mật với MFA, đơn giản hóa quản lý quyền.
    - **Ứng dụng**: Phù hợp cho tổ chức cần quản lý truy cập tập trung.
  - **Hoạt động**:
    - Đọc tài liệu AWS về AWS Identity Center và SSO.
    - Xem video AWS Study Group về tích hợp Identity Center với Active Directory.
    - Ghi chú mối liên hệ giữa Identity Center, Cognito, và Organizations.
    - Liên hệ với lý thuyết IAM Roles (Module 05-02) để hiểu cách gán quyền.
- **Kết quả**: Hiểu rõ AWS Identity Center, đặc biệt là SSO và tích hợp với danh tính doanh nghiệp.
