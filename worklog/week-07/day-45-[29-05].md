## 💼 Công việc đã thực hiện

### 1. Học lý thuyết Module 05-Lab18-01: Security Standards 
- **Mô tả**: Nghiên cứu và ghi chú về các tiêu chuẩn bảo mật trong AWS Security Hub:
  - **Nội dung chính**:
    - **AWS Foundational Security Best Practices**:
      - Tập hợp các bài kiểm tra bảo mật do chuyên gia AWS thiết kế.
      - Đánh giá tài khoản và tài nguyên theo thực hành tối ưu (best practices).
      - Áp dụng cho các dịch vụ phổ biến như S3, EC2, RDS.
    - **CIS AWS Foundations Benchmark**:
      - Bộ tiêu chuẩn từ Center for Internet Security (CIS).
      - Tự động kiểm tra sự tuân thủ với các yêu cầu bảo mật cụ thể (ví dụ: bật MFA, mã hóa dữ liệu).
    - **PCI DSS**:
      - Tiêu chuẩn bảo mật cho dữ liệu thẻ ngân hàng (Payment Card Industry Data Security Standard).
      - Tự động kiểm tra tuân thủ các yêu cầu liên quan đến lưu trữ, xử lý, truyền dữ liệu thẻ.
  - **Hoạt động**:
    - Đọc tài liệu AWS về các tiêu chuẩn bảo mật trong Security Hub.
    - Xem video AWS Study Group về AWS Foundational Security Best Practices và CIS Benchmark.
    - Ghi chú sự khác biệt: AWS Best Practices (tập trung vào dịch vụ AWS), CIS (cấu hình bảo mật chung), PCI DSS (dành riêng cho dữ liệu thẻ).
    - Liên hệ với Module 05-07 (AWS Security Hub) để hiểu cách các tiêu chuẩn được áp dụng trong Security Hub.
- **Kết quả**: Hiểu rõ ba tiêu chuẩn bảo mật và vai trò của chúng trong việc tăng cường bảo mật tài khoản AWS.
- **Tools/Tech**: AWS Documentation, AWS Study Group Videos, Notion (ghi chú).
- **Links**: [Module 05 lab18](https://000018.awsstudygroup.com/)

### 2. Thực hành Module 05-Lab18-02: Enable Security Hub ⏱️ [3 giờ]
- **Mô tả**: Kích hoạt AWS Security Hub và cấu hình các tiêu chuẩn bảo mật:
  - **Bước thực hiện**:
    - Đăng nhập vào **AWS Management Console**, tìm kiếm và chọn **Security Hub**.
    - Trong trang **Welcome to AWS Security Hub**:
      - Chọn các tiêu chuẩn bảo mật: 
        - AWS Foundational Security Best Practices.
        - CIS AWS Foundations Benchmark.
        - PCI DSS.
      - Nhấn **Enable Security Hub**.
    - Nhận thông báo yêu cầu kích hoạt **AWS Config**:
      - Trong **AWS Config Console**, chọn region `ap-southeast-1` (Singapore).
      - Kích hoạt ghi nhận tất cả tài nguyên (All resources) trong region và các tài nguyên global (ví dụ: IAM).
      - Chờ AWS Config khởi tạo (~5 phút).
    - Quay lại **Security Hub Console**, chờ Security Hub đánh giá **Security Score** (~10-15 phút).
    - Kiểm tra dashboard Security Hub, ghi nhận Security Score ban đầu (giả định: 70%, do không có dữ liệu thực tế).
  - **Kết quả**: Security Hub được kích hoạt thành công, tích hợp với AWS Config, và hiển thị Security Score dựa trên ba tiêu chuẩn bảo mật.
- **Tools/Tech**: AWS Security Hub, AWS Config, AWS Management Console.
- **Links**: [Module 05 lab18](https://000018.awsstudygroup.com/)
