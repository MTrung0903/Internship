## 💼 Công việc đã thực hiện

### 1. Thực hành Module 05-Lab18-03: Score for Each Set of Criteria 
- **Mô tả**: Kiểm tra điểm đánh giá bảo mật (Security Score) và các rủi ro trong AWS Security Hub:
  - **Bước thực hiện**:
    - Đăng nhập vào **AWS Management Console**, tìm kiếm và chọn **Security Hub**.
    - Trong **Security Hub Console**, chọn **Security standards** ở thanh điều hướng bên trái.
    - Xem thông tin tổng quan về Security Score cho ba tiêu chuẩn:
      - AWS Foundational Security Best Practices (giả định: 70%).
      - CIS AWS Foundations Benchmark (giả định: 65%).
      - PCI DSS (giả định: 60%).
    - Chọn **View results** cho từng tiêu chuẩn để xem chi tiết Security Findings:
      - Xác định các rủi ro bảo mật (giả định: EC2 instance không bật MFA, S3 bucket public access).
    - Vô hiệu hóa một tiêu chí (theo ví dụ trong task):
      - Trong danh sách **AWS Foundational Security Best Practices**, chọn tiêu chí: *EC2 instances managed by Systems Manager should have an association compliance status of COMPLIANT*.
      - Trong trang chi tiết tiêu chí, chọn **Enabled** > **Disable**.
      - Nhập lý do: "Not applicable for current lab environment".
      - Nhấn **Disable** để loại bỏ tiêu chí khỏi đánh giá.
  - **Kết quả**: Xem được Security Score và Security Findings, vô hiệu hóa thành công một tiêu chí bảo mật.
- **Tools/Tech**: AWS Security Hub, AWS Management Console.
- **Links**: [Module 05 lab18](https://000018.awsstudygroup.com/)

### 2. Thực hành Module 05-Lab18-04: Clean Up Resources
- **Mô tả**: Tắt AWS Security Hub và AWS Config để tránh phát sinh chi phí:
  - **Bước thực hiện**:
    - **Tắt Security Hub**:
      - Trong **Security Hub Console**, chọn **Settings** ở thanh bên trái.
      - Trong tab **General**, cuộn xuống và chọn **Disable AWS Security Hub**.
      - Trong prompt xác nhận, nhấn **Disable AWS Security Hub**.
    - **Tắt AWS Config**:
      - Trong **AWS Config Console** (region `ap-southeast-1`):
        - Chọn **Settings** > **Recorder** > **Stop recording**.
        - Xóa **Delivery Channel** và **Configuration Recorder** để ngừng ghi nhận tài nguyên.
    - Kiểm tra **Billing Dashboard** để đảm bảo không phát sinh chi phí từ Security Hub hoặc AWS Config.
  - **Kết quả**: Security Hub và AWS Config được tắt thành công, không phát sinh chi phí.
- **Tools/Tech**: AWS Security Hub, AWS Config, AWS Billing.
- **Links**: [Module 05 lab18](https://000018.awsstudygroup.com/)
