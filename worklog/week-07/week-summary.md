## 📚 Kiến thức học được
- **Kỹ thuật**:
  - **Dịch vụ AWS**: IAM, Cognito, Organizations, Identity Center, KMS, Security Hub, Config, Lambda, CloudWatch Events, VPC, EC2, Security Group.
  - **Công cụ**: AWS Management Console, Notion (ghi chú), Slack Webhook, AWS Documentation, AWS Study Group Videos, AWS re:Invent Videos.
  - **Kiến trúc**: Tích hợp Security Hub với AWS Config, Lambda với EC2/CloudWatch Events, và Cognito với serverless applications.
- **Lý thuyết**:
  - **Shared Responsibility Model**: Phân chia trách nhiệm bảo mật giữa AWS và khách hàng.
  - **IAM**: Quản lý quyền truy cập với IAM Roles, Policies (Deny/Allow).
  - **Cognito**: User Pools (đăng nhập), Identity Pools (cấp quyền AWS), tích hợp SAML/OIDC.
  - **Organizations**: Quản lý tài khoản với SCPs, Consolidated Billing.
  - **Identity Center**: SSO cho tài khoản AWS và ứng dụng doanh nghiệp.
  - **KMS**: Quản lý khóa mã hóa, envelope encryption, tích hợp với S3/EBS/RDS.
  - **Security Hub**: Giám sát bảo mật, Security Findings, hỗ trợ CIS/PCI DSS.
  - **Lambda**: Tự động hóa EC2 start/stop, tích hợp Slack Webhook.
- **Kỹ năng mềm**:
  - Ghi chú chi tiết, phân tích JSON policies, xử lý lỗi cấu hình (IAM, Security Hub, Lambda).
  - Quản lý thời gian hiệu quả giữa lý thuyết và thực hành.
  - Tự học qua tài liệu AWS, video Study Group, và re:Invent.
