### 1. Học lý thuyết Module 05-06: Amazon Key Management Service 
- **Mô tả**: Nghiên cứu và ghi chú về Amazon Key Management Service (KMS):
  - **Nội dung chính**:
    - **Khái niệm**: AWS KMS là dịch vụ quản lý khóa mã hóa (cryptographic keys) để bảo vệ dữ liệu trong các dịch vụ AWS và ứng dụng khách hàng.
    - **Chức năng chính**:
      - Tạo, quản lý, và xoay vòng khóa mã hóa (KMS keys) để mã hóa/dịch mã dữ liệu.
      - Hỗ trợ mã hóa phía máy chủ (server-side encryption) cho các dịch vụ như S3, EBS, RDS, DynamoDB.
      - Cung cấp khóa đối xứng (symmetric) và bất đối xứng (asymmetric) cho các nhu cầu mã hóa khác nhau.
      - Tích hợp với AWS CloudTrail để ghi lại việc sử dụng khóa (key usage auditing).
      - Hỗ trợ chính sách khóa (key policies) để kiểm soát quyền truy cập vào KMS keys.
    - **Tính năng bảo mật**:
      - Sử dụng Hardware Security Modules (HSMs) để lưu trữ khóa an toàn.
      - Hỗ trợ mã hóa envelope (envelope encryption) để bảo vệ dữ liệu hiệu quả.
      - Tích hợp với IAM để kiểm soát quyền truy cập vào khóa.
    - **Lợi ích**:
      - Đơn giản hóa quản lý khóa mã hóa, tuân thủ các tiêu chuẩn như FIPS 140-2.
      - Tăng cường bảo mật dữ liệu trên nhiều dịch vụ AWS.
    - **Ứng dụng**: Mã hóa dữ liệu nhạy cảm trong S3 buckets, EBS volumes, hoặc ứng dụng serverless.
  - **Hoạt động**:
    - Đọc tài liệu AWS về KMS, tập trung vào KMS keys và envelope encryption.
    - Xem video AWS Study Group về tích hợp KMS với S3 (liên hệ với Module 04-Lab57).
    - Ghi chú sự khác biệt giữa symmetric và asymmetric keys.
    - Phân tích ví dụ key policy JSON để hiểu cách kiểm soát quyền.
- **Kết quả**: Hiểu rõ cách AWS KMS quản lý khóa mã hóa và ứng dụng trong bảo mật dữ liệu.
- **Tools/Tech**: AWS Documentation, AWS Study Group Videos, Notion (ghi chú).

### 2. Học lý thuyết Module 05-07: AWS Security Hub 
- **Mô tả**: Nghiên cứu và ghi chú về AWS Security Hub:
  - **Nội dung chính**:
    - **Khái niệm**: AWS Security Hub là dịch vụ quản lý bảo mật tập trung, cung cấp cái nhìn tổng quan về tình trạng bảo mật và tuân thủ trên các tài khoản AWS.
    - **Chức năng chính**:
      - Thu thập và phân tích dữ liệu bảo mật từ các dịch vụ AWS (GuardDuty, Inspector, Macie) và đối tác bên thứ ba.
      - Cung cấp Security Findings (kết quả kiểm tra bảo mật) để phát hiện lỗ hổng, cấu hình sai, hoặc mối đe dọa.
      - Hỗ trợ các tiêu chuẩn tuân thủ như CIS AWS Foundations, PCI DSS, AWS Foundational Security Best Practices.
      - Tích hợp với AWS Organizations để quản lý bảo mật trên nhiều tài khoản.
      - Hỗ trợ tự động hóa phản hồi qua AWS Lambda hoặc AWS Systems Manager.
    - **Lợi ích**:
      - Cung cấp dashboard tổng quan để theo dõi bảo mật.
      - Giảm thời gian phát hiện và khắc phục vấn đề bảo mật.
      - Tăng cường khả năng tuân thủ quy định.
    - **Ứng dụng**: Phù hợp cho tổ chức cần giám sát bảo mật và tuân thủ trên quy mô lớn.
  - **Hoạt động**:
