## 💼 Công việc đã thực hiện

### 1. Tạo Continuous Access Share 
- **Mô tả**: Tạo chia sẻ Truy cập Liên tục (Continuous Access Share) cho Microsoft SQL Server trên FSx 
- **Kết quả**: Continuous Access Share `SQL CA Share` được tạo thành công, sẵn sàng cho SQL Server High Availability.
- **Tools/Tech**: AWS FSx, Windows PowerShell, File Explorer, AWS Secrets Manager, Remote Desktop.
- **Links**: [AWS FSx Continuous Availability](https://docs.aws.amazon.com/fsx/latest/WindowsGuide/using-file-shares.html#continuous-availability)

### 2. Thực hành Module 04-Lab25-11: Scale Throughput Capacity 
- **Mô tả**: Tăng throughput capacity của FSx 
- **Kết quả**: Throughput capacity tăng thành công lên 64 MB/s, hiệu suất cải thiện đáng kể.
- **Tools/Tech**: AWS FSx, Windows PowerShell, DiskSpd.
- **Links**: [AWS FSx Scaling Throughput](https://docs.aws.amazon.com/fsx/latest/WindowsGuide/managing-throughput-capacity.html)

### 3. Thực hành Module 04-Lab25-12: Scale Storage Capacity
- **Mô tả**: Tăng storage capacity của FSx 
- **Kết quả**: Storage capacity tăng thành công lên ~35.2 GiB, dung lượng mới sẵn sàng ngay lập tức.
- **Tools/Tech**: AWS FSx, CloudWatch.
- **Links**: [AWS FSx Scaling Storage](https://docs.aws.amazon.com/fsx/latest/WindowsGuide/managing-storage-capacity.html)
