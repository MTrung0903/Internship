## 💼 Công việc đã thực hiện

### 1. Thực hành Module 03-Lab13-02.2: Deploy Infrastructure
- **Mô tả**: Sử dụng CloudFormation template  để triển khai hạ tầng:
  - Tạo EBS Volume, RDS Database (MySQL), DynamoDB Table, và EFS File System trong cùng một VPC.
  - Ghi lại ARN của các tài nguyên. 
- **Kết quả**: Hạ tầng triển khai thành công, tất cả tài nguyên nằm trong cùng VPC, ARN được ghi lại.
- **Tools/Tech**: AWS Management Console, AWS CloudFormation.
- **Links**: [Module 03-Lab13](https://000013.awsstudygroup.com/)

### 2. Thực hành Module 03-Lab13-03: Create Backup Plan 
- **Mô tả**: Tạo Backup Plan trong AWS Backup:
  - Điều hướng đến AWS Backup, chọn **Backup plans** > **Create backup plan**.
  - Sử dụng tùy chọn **Build a new plan**.
  - Chọn tài nguyên: EBS Volume, RDS Database, DynamoDB Table, EFS File System.
  - Cấu hình tần suất sao lưu (hàng ngày, 1:00 AM UTC) và retention period (7 ngày).
- **Kết quả**: Backup Plan được tạo thành công, bao gồm các tài nguyên được chỉ định.
- **Tools/Tech**: AWS Management Console, AWS Backup.
- **Links**: [Module 03-Lab13](https://000013.awsstudygroup.com/)

### 3. Thực hành Module 03-Lab13-04: Set up Notifications 
- **Mô tả**: Cấu hình thông báo cho Backup Plan:
  - Tạo SNS Topic trong AWS SNS.
  - Thêm subscriber và xác minh email.
  - Liên kết SNS Topic với Backup Plan trong AWS Backup để thông báo khi sao lưu hoàn thành hoặc gặp lỗi.
- **Kết quả**: Nhận được email xác minh và thông báo thử nghiệm từ SNS Topic.
- **Tools/Tech**: AWS Management Console, AWS SNS.
- **Links**: [Module 03-Lab13](https://000013.awsstudygroup.com/)

### 4. Thực hành Module 03-Lab13-05: Test Restore 
- **Mô tả**: Kiểm tra khôi phục dữ liệu từ bản sao lưu:
  - Trong AWS Backup, chọn bản sao lưu của EFS File System.
  - Thực hiện **Restore** vào cùng VPC, xác nhận dữ liệu khôi phục bằng cách kiểm tra file trong EFS.
  - Ghi lại thời gian khôi phục (khoảng 5 phút cho EFS 100MB).
- **Kết quả**: Dữ liệu EFS được khôi phục thành công, xác nhận bằng truy cập file.
- **Tools/Tech**: AWS Management Console, AWS Backup, AWS EFS.
- **Links**: [Module 03-Lab13](https://000013.awsstudygroup.com/)
