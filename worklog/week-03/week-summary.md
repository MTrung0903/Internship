## 📚 Kiến thức học được
- **Kỹ thuật**:
  - **Dịch vụ AWS**: EC2 (User Data, Metadata, Auto Scaling), EFS, FSx (Windows File Server, Lustre), Lightsail, MGN, Transit Gateway, AWS Backup, SNS, S3, CloudFormation.
  - **Công cụ**: AWS Management Console, CloudFormation Designer, SSH client, draw.io.
  - **Kiến trúc**: Thiết lập Auto Scaling Group, cấu hình Transit Gateway, VPC Peering, Backup Plan, và tích hợp SNS để thông báo.
- **Lý thuyết**:
  - **EC2**: User Data (tự động hóa cấu hình), Metadata (truy xuất thông tin instance), Auto Scaling (điều chỉnh tài nguyên động), Instance Types, EBS, Instance Store.
  - **Lưu trữ**: EFS (chia sẻ file), FSx (Windows File Server, Lustre), S3 (lưu trữ file và template).
  - **Kết nối mạng**: VPC Peering (kết nối 1:1), Transit Gateway (kết nối nhiều VPC), Route Tables, Cross-Peer DNS.
  - **Sao lưu và khôi phục**: AWS Backup (sao lưu tập trung EBS, RDS, DynamoDB, EFS), SNS (thông báo), retention period.
  - **Tự động hóa**: CloudFormation (triển khai hạ tầng qua YAML), Lightsail (VPS đơn giản), MGN (di chuyển ứng dụng).
- **Kỹ năng mềm**:
  - Ghi chú chi tiết, quản lý thời gian, tự học qua video và tài liệu AWS.
  - Giải quyết vấn đề: Xử lý lỗi cấu hình SNS, Route Tables, CloudFormation, và kiểm tra kết nối `ping`.
  - Trực quan hóa kiến trúc qua sơ đồ draw.io.
