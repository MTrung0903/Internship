### 💡 Concepts & Theory
- **New Concepts**:
  
  - **Metadata**: Thông tin instance (Instance ID, IP, Security Groups).
  - **Auto Scaling**: Tự động điều chỉnh số lượng instance dựa trên tải, sử dụng Auto Scaling Group, Scaling Policies (Scale Out/In), Health Checks, và Scheduled Scaling.
- **Best Practices**: Sử dụng User Data để tự động hóa triển khai; cấu hình Auto Scaling với số lượng instance tối thiểu/tối đa hợp lý; kiểm tra log User Data để xử lý lỗi.
- **Industry Knowledge**: Auto Scaling giúp tối ưu hóa hiệu suất và chi phí cho ứng dụng web hoặc hệ thống phân tích dữ liệu.
