## 💼 Công việc đã thực hiện

### 1. Nghiên cứu Module 04-04: Snow Family - Storage Gateway - Backup
- **Mô tả**: Đọc và ghi chú lý thuyết về các dịch vụ:
  - **Snow Family**:
    - **Snowcone**: Thiết bị nhỏ (~8TB), phù hợp cho di chuyển dữ liệu quy mô nhỏ.
    - **Snowball Edge**: Dung lượng lớn (~100TB), hỗ trợ tính toán tại chỗ.
    - **Snowmobile**: Xe tải cho dữ liệu petabytes, dành cho di chuyển dữ liệu lớn.
    - Ứng dụng: Chuyển dữ liệu từ on-premises lên AWS khi kết nối internet hạn chế.
  - **Storage Gateway**:
    - Cầu nối hybrid giữa on-premises và AWS cloud.
    - Các chế độ: File Gateway (đồng bộ file lên S3), Volume Gateway (block storage), Tape Gateway (tape backup lên S3).
  - **AWS Backup**:
    - Dịch vụ quản lý backup tập trung cho EBS, RDS, DynamoDB, S3, v.v.
    - Hỗ trợ tự động hóa sao lưu và phục hồi.
- **Kết quả**: Hiểu rõ các khái niệm và ứng dụng của Snow Family, Storage Gateway, và AWS Backup.
