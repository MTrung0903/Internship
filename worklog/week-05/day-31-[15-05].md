### 1. Thực hành Module 04-Lab14-01: VMware Workstation ⏱️ [2 giờ]
- **Mô tả**: Cài đặt VMware Workstation và tạo máy ảo Ubuntu:
  - Cài đặt **VMware Workstation Pro** từ [VMware website](https://www.vmware.com/products/workstation-pro.html) trên máy local (sử dụng bản dùng thử 30 ngày).
  - Tải file ISO Ubuntu Desktop (phiên bản mới nhất) từ [Ubuntu Releases](https://releases.ubuntu.com/).
  - Trong VMware Workstation:
    - Chọn **Create a New Virtual Machine** > **Typical (recommended)**.
    - Chọn file ISO Ubuntu Desktop.
    - Cấu hình Easy Install: Username `awsstudent`, password `123456`.
    - Đặt tên VM: `Ubuntu-2025`.
    - Thiết lập dung lượng disk: 20GB.
    - Nhấn **Finish** để cài đặt Ubuntu.
  - Sau khi cài đặt, cấu hình VM:
    - Cài đặt OpenSSH Server: `sudo apt update && sudo apt install openssh-server`.
    - Kiểm tra kết nối SSH từ máy local: `ssh awsstudent@localhost`.
- **Kết quả**: Máy ảo Ubuntu được tạo và cấu hình thành công, sẵn sàng xuất sang AWS.
- **Tools/Tech**: VMware Workstation Pro, Ubuntu Desktop, OpenSSH.
- **Links**: 
  - [VMware Workstation Pro](https://www.vmware.com/products/workstation-pro.html)
  - [Ubuntu Releases](https://releases.ubuntu.com/)

### 2. Thực hành Module 04-Lab14-02.1: Export Virtual Machine from On-premises ⏱️ [1 giờ]
- **Mô tả**: Xuất máy ảo Ubuntu từ VMware Workstation:
  - Mở **VMware Workstation**, chọn VM `Ubuntu-2025`.
  - Vào **File** > **Export to OVF**.
  - Chọn thư mục lưu file xuất: `C:\VM-Export\Ubuntu-2025`.
  - Chờ khoảng 5 phút để quá trình xuất hoàn tất.
  - Kiểm tra thư mục xuất, xác nhận file `Ubuntu-2025-disk1.vmdk` được tạo.
- **Kết quả**: Máy ảo được xuất thành công dưới định dạng OVF, file `Ubuntu-2025-disk1.vmdk` sẵn sàng để tải lên S3.
- **Tools/Tech**: VMware Workstation Pro.
- **Links**: [VMware Export OVF](https://docs.vmware.com/en/VMware-Workstation-Pro/17/com.vmware.ws.using.doc/GUID-7E8B2F12-6B5A-4E9E-9B6A-0A3E0B6B1F2E.html)

### 3. Thực hành Module 04-Lab14-02.2: Upload Virtual Machine to AWS ⏱️ [1.5 giờ]
- **Mô tả**: Tạo S3 bucket và tải file VM lên:
  - Tạo bucket:
    - Trong **S3 Console** > **Create bucket**:
      - Đặt tên: `import-bucket-trung-2025` (duy nhất toàn cầu).
      - Vùng: `ap-southeast-1`.
      - Bỏ chọn **Block all public access** (chấp nhận cảnh báo để hỗ trợ VM Import/Export).
      - Nhấn **Create bucket**.
  - Tải file VM:
    - Trong **S3 Console** > bucket `import-bucket-trung-2025` > **Objects** > **Upload**.
    - Kéo/thả file `Ubuntu-2025-disk1.vmdk` từ `C:\VM-Export\Ubuntu-2025` hoặc chọn **Add files**.
    - Nhấn **Upload**, chờ khoảng 10-15 phút để hoàn tất (tùy kích thước file và tốc độ mạng).
  - Kiểm tra file trong bucket để xác nhận tải lên thành công.
- **Kết quả**: Bucket `import-bucket-trung-2025` được tạo, file `Ubuntu-2025-disk1.vmdk` được tải lên S3 thành công.
- **Tools/Tech**: AWS Management Console, AWS S3.
- **Links**: [AWS S3 Create Bucket](https://docs.aws.amazon.com/AmazonS3/latest/userguide/creating-bucket.html)

### 4. Dọn dẹp tài nguyên ⏱️ [1 giờ]
- **Mô tả**: Dọn dẹp tài nguyên để tránh phát sinh chi phí:
  - **Xóa S3 Bucket**: Trong **S3 Console**, chọn `import-bucket-trung-2025` > **Empty** (nhập `permanently delete`) > **Delete bucket** (nhập tên bucket).
  - **Xóa file VM local**: Xóa thư mục `C:\VM-Export\Ubuntu-2025` trên máy local để giải phóng dung lượng.
  - Kiểm tra chi phí trong **Billing Dashboard** để đảm bảo không phát sinh chi phí.
- **Kết quả**: Tất cả tài nguyên trên AWS và local được xóa sạch, không phát sinh chi phí.
- **Tools/Tech**: AWS Management Console, AWS S3, File Explorer.
- **Links**: [AWS Resource Cleanup Guide](https://docs.aws.amazon.com/AmazonS3/latest/userguide/delete-bucket.html)
