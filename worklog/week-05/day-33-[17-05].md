### 💡 Concepts & Theory
- **New Concepts**:
  - **Storage Gateway**: Cầu nối hybrid giữa on-premises và AWS, sử dụng File Share để đồng bộ dữ liệu.
  - **SMB File Share**: Giao thức phù hợp cho Windows, tích hợp với S3.
  - **EC2 for Storage Gateway**: Sử dụng instance m4.large với volume Cache 150 GiB.
- **Best Practices**: Bỏ chọn Block Public Access khi cần cho Storage Gateway; cấu hình Security Group đúng port; dọn dẹp tài nguyên ngay sau lab.
- **Industry Knowledge**: Storage Gateway là giải pháp hiệu quả để đồng bộ dữ liệu từ on-premises sang AWS cloud.
