## 📚 Kiến thức học được
- **Kỹ thuật**:
  - **Dịch vụ AWS**: S3 (static website, versioning, replication, Access Points, Storage Classes), CloudFront, Storage Gateway, EBS, EFS, Glacier, Snow Family.
  - **Công cụ**: AWS Management Console, Windows Command Prompt, SSH client, draw.io, Notion (ghi chú).
  - **Kiến trúc**: Tích hợp Storage Gateway với S3, S3 với CloudFront, và tối ưu hóa lưu trữ với Glacier qua lifecycle rules.
- **Lý thuyết**:
  - **S3**: Static website hosting, CORS, Bucket Policy/IAM/ACL, versioning, replication, Access Points, Storage Classes (Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier, Deep Archive).
  - **Storage Gateway**: File Share SMB để đồng bộ dữ liệu on-premises với S3.
  - **CloudFront**: CDN phân phối nội dung từ Edge Locations, tăng tốc độ và bảo mật website tĩnh.
  - **Lưu trữ AWS**: EBS (Block Storage), EFS (File Storage), Glacier (Archiving), Snow Family (Physical data transfer).
  - **Tối ưu hóa**: Sử dụng prefix để tổ chức object, Transfer Acceleration, và lifecycle rules để tiết kiệm chi phí.
- **Kỹ năng mềm**:
  - Ghi chú chi tiết, quản lý thời gian, tự học qua video AWS Study Group và AWS Documentation.
  - Giải quyết vấn đề: Xử lý lỗi cấu hình File Share, CloudFront cache, IAM policy, và quyền truy cập S3.
  - Trực quan hóa kiến trúc qua sơ đồ draw.io.
